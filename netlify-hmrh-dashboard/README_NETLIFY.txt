HMRH HSE Dashboard - Netlify Deploy

Pasta pronta para Netlify:
netlify-hmrh-dashboard/

Ficheiro principal:
index.html

Como publicar:
1. Abrir https://app.netlify.com/drop
2. Arrastar a pasta netlify-hmrh-dashboard para a pagina
   ou arrastar o ficheiro netlify-hmrh-dashboard.zip
3. Netlify vai gerar um link publico para partilhar com a equipa.

Importante:
Esta pasta inclui relatorios, reunioes, PDF do simulacro e fotografias.
Se a informacao for interna/confidencial, use um site protegido ou partilhe o link apenas com a equipa autorizada.
